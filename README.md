# CryptoRadar Privacy Policy

Static privacy-policy website for GitHub Pages.

## Files

- `index.html` — page structure and privacy-policy content
- `styles.css` — complete responsive design
- `script.js` — active section highlighting

## GitHub Pages

1. Create a GitHub repository.
2. Upload these three files to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save and wait for GitHub Pages to publish the site.

Your privacy-policy URL will normally look like:

`https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/`

## Important

Replace the sample policy text with the actual privacy practices of the CryptoRadar app before publishing it as your official Google Play privacy-policy URL.

Also replace `support@cryptoradar.app` if that is not your real support address.
